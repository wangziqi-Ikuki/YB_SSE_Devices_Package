# YB 合成工站操作运行指南

本文用于在本机 Windows PowerShell 上启动 Uni-Lab OS、YB 设备包和内置前端，并从仿真机或真实 PLC 运行已发布的工作流。

## 0. 重要区别

- **仿真机**连接 `127.0.0.1:5020`，只在电脑内模拟 PLC、机械臂、扫码、称量和声共振，不会驱动现场设备。
- **真机**连接 `192.168.1.10:502`、Unit ID `1`（这些参数必须以现场确认结果为准）。真机启动后，工作流提交可能使机械臂和 PLC 动作。
- 真机和仿真机使用不同启动图，不能混用：
  - 仿真：`deployment/graphs/local-sim.json`
  - 真机：`deployment/graphs/real-plc.json`
- 不要同时启动旧的 Qt 上位机/HMI 自动流程，避免多个程序同时写 PLC 命令。

以下命令默认在 PowerShell 中执行，且仓库位于：

```powershell
Set-Location "C:\Users\DP\Desktop\New_YB_package"
$env:PYTHONPATH = "C:\Users\DP\Desktop\New_YB_package\Uni-Lab-OS"
$python = "C:\ProgramData\miniforge3\envs\unilabv2\python.exe"
$package = "C:\Users\DP\Desktop\New_YB_package\YB_SSE_Devices_Package"
```

## 1. 启动仿真机

先启动设备包自带的 Modbus 仿真器。这个窗口可以保持打开，也可以使用 `Start-Process` 在后台启动。

```powershell
Set-Location "C:\Users\DP\Desktop\New_YB_package"
$env:PYTHONPATH = "C:\Users\DP\Desktop\New_YB_package\YB_SSE_Devices_Package"
$python = "C:\ProgramData\miniforge3\envs\unilabv2\python.exe"

& $python -m yb_sse_devices.modbus_sim_server `
  --host 127.0.0.1 --port 5020 `
  --handshake-delay 0.5 `
  --acoustic-process-duration 5.0 `
  --log-file "C:\Users\DP\Desktop\New_YB_package\YB_SSE_Devices_Package\.unilabos\logs\yb-modbus-sim.jsonl" `
  --verbose
```

如果需要后台启动：

```powershell
Start-Process -WindowStyle Hidden -FilePath $python -ArgumentList @(
  '-m','yb_sse_devices.modbus_sim_server',
  '--host','127.0.0.1','--port','5020',
  '--handshake-delay','0.5',
  '--acoustic-process-duration','5.0',
  '--log-file',"$package\.unilabos\logs\yb-modbus-sim.jsonl",
  '--verbose'
)
```

检查仿真端口：

```powershell
Get-NetTCPConnection -LocalAddress 127.0.0.1 -LocalPort 5020 -State Listen
```

## 2. 启动真实 PLC

启动真机前，必须确认 PLC IP、Modbus TCP 端口、Unit ID、远程自动模式、急停/门/光栅/机器人互锁和现场物料位置。确认前不要执行工作流。

```powershell
Set-Location "C:\Users\DP\Desktop\New_YB_package"
$env:PYTHONPATH = "C:\Users\DP\Desktop\New_YB_package\Uni-Lab-OS"
$python = "C:\ProgramData\miniforge3\envs\unilabv2\python.exe"

& $python -m unilabos workspace start `
  --workspace "C:\Users\DP\Desktop\New_YB_package\YB_SSE_Devices_Package" `
  --graph "C:\Users\DP\Desktop\New_YB_package\YB_SSE_Devices_Package\deployment\graphs\real-plc.json" `
  --runtime-mode normal `
  --startup-mode develop `
  --wait 180 `
  --json
```

真机启动图当前的候选配置是 `192.168.1.10:502`、Unit ID `1`。如果现场确认值不同，应先修改设备包的部署配置并重新检查，不要直接试运行。

## 3. 启动 OS 和内置前端

OS Backend/Edge 由 `workspace start` 统一启动。启动后查看状态：

```powershell
$env:PYTHONPATH = "C:\Users\DP\Desktop\New_YB_package\Uni-Lab-OS"
& "C:\ProgramData\miniforge3\envs\unilabv2\python.exe" -m unilabos workspace status `
  --workspace "C:\Users\DP\Desktop\New_YB_package\YB_SSE_Devices_Package" `
  --json
```

确认输出中 Backend 和 Edge 都是 `ready`，并确认 `graph` 是本次想使用的 `local-sim.json` 或 `real-plc.json`。

如果使用前端源码开发页面，在**另一个 PowerShell 窗口**执行：

```powershell
Set-Location "C:\Users\DP\Desktop\New_YB_package\Uni-Lab-OS\frontend"
npm run dev -- --host 127.0.0.1 --port 4174
```

然后打开：

```text
http://127.0.0.1:4174/console/
```

如果使用 Workspace Backend 提供的内置生产前端，则打开状态输出中的 Backend 地址并追加 `/console/`，例如：

```text
http://127.0.0.1:<backend-port>/console/
```

## 4. 在前端启动工作流

当前工作流为“合成工站 加粉加珠流程 料架2”。按下面顺序操作：

1. 进入“工作流”，选择已发布的工作流修订版。
2. 点击“进入运行准备”。
3. 选择配方、托盘规格、默认坩埚规格和实际使用槽位。托盘规格改变后，只选择该托盘实际存在的槽位。
4. 设置是否有加珠瓶和球磨珠数量；没有加珠瓶时选择“否”，数量填 `0`。
5. 检查配方对应的物料、料架位置、坩埚返回位置和声共振参数。页面中的底层 PLC 命令寄存器不需要手工填写。
6. 点击“运行 Preflight”。等待输入、资源/设备、运行条件三个检查项全部通过。
7. **Preflight 通过后，由用户手动点击“提交任务”。** 参数填完不会自动提交任务。
8. 打开“任务”页面，观察节点状态、设备状态和动作结果。出现人工确认节点时，按页面提示完成现场操作后再确认通过。

工作流通常包括：人工确认料架 2 已放好托盘和坩埚、命令 7 上托盘到料架 1、命令 3 扫码/开盖/称粉/加珠、各槽位称量结果确认、料瓶归位、坩埚返回料架 1，以及后续声共振上料、等待声共振完成和下料。

## 5. 停止服务

停止 OS、设备进程和内置前端托管组件：

```powershell
$env:PYTHONPATH = "C:\Users\DP\Desktop\New_YB_package\Uni-Lab-OS"
& "C:\ProgramData\miniforge3\envs\unilabv2\python.exe" -m unilabos workspace stop `
  --workspace "C:\Users\DP\Desktop\New_YB_package\YB_SSE_Devices_Package" `
  --component all `
  --wait 60 `
  --json
```

如果仿真器是前台运行，回到该窗口按 `Ctrl+C`；如果是后台运行，可按端口查找并停止：

```powershell
$sim = Get-NetTCPConnection -LocalAddress 127.0.0.1 -LocalPort 5020 -State Listen -ErrorAction SilentlyContinue
if ($sim) { Stop-Process -Id $sim.OwningProcess -Force }
```

## 6. 常用排查

- **OS 显示已连接但机器不动：** 先确认启动图、PLC 远程自动模式、IP/端口/Unit ID 和互锁；不要重复提交同一任务。
- **仿真任务卡在 `wait_acoustic_process`：** 先确认仿真器在 `5020` 监听。命令 8 的 `40107` 和 `40109` 必须先看到运行中再看到完成，否则防误判会把旧的完成值当成残留。振动、马弗炉和焦耳热按命令里填写的时间走，填 3 分钟就等 3 分钟。不要用清空寄存器代替任务恢复。
- **真机与仿真状态混乱：** 停止 OS 后再切换启动图，并确保库存状态与启动图一致；不要在同一运行目录直接混切。
- **需要查看日志：** OS 日志在设备包 `.unilabos\logs\` 下，仿真器日志为 `yb-modbus-sim.jsonl`。

## 7. 安全边界

仿真机可以反复测试。真实 PLC 启动并不等于机械臂已经运动，真正产生动作的是工作流进入运行状态并提交任务后发送的 PLC 命令。真机联调应由现场人员确认空载、互锁和安全区域；出现异常时先停止调度并按现场 SOP 处理。
